Announcing the immediate availability of Passbolt's helm chart 2.2.1.

## Bumping Passbolt version

This version of the Helm chart bumps the Passbolt version from 5.16 to 5.17. This Passbolt version also includes PHP 8.4.27, which fixes CVE-2026-109618 and CVE-2026-109619. Read more about this on the [PHP Security Advisory](https://www.php.net/archive/2026.php#2026-10-21-5).

Thanks to all the community members that helped us to improve this chart! :tada:
